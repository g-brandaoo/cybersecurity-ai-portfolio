---

**sobre**

Esta pasta reúne os laboratórios práticos utilizados para transformar os conceitos estudados no portfólio em experiências técnicas.

Os laboratórios devem permitir testar conceitos em ambientes controlados, registrar resultados e desenvolver evidências práticas.

---

**objetivo**

Utilizar laboratórios para desenvolver:

- prática técnica;
- capacidade de investigação;
- análise de vulnerabilidades;
- identificação de riscos;
- implementação de controles;
- troubleshooting;
- automação;
- documentação técnica;
- mentalidade de segurança.
