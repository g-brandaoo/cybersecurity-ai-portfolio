**projects**

<sub>Projetos práticos e laboratórios de Cybersecurity, Cloud Security, Automação e AI Security.</sub>

---

**sobre**

Esta pasta reúne os projetos práticos desenvolvidos durante a evolução do portfólio.

Cada projeto tem como objetivo transformar conceitos estudados em **implementações, testes, análises e evidências práticas**.

---

**objetivo**

Os projetos foram planejados para desenvolver experiência prática em:

- Cybersecurity
- Segurança ofensiva
- Segurança defensiva
- SOC
- Web Security
- Cloud Security
- AWS
- IAM
- DevSecOps
- Supply Chain Security
- Automação
- AI Security

**evidências**

Os projetos podem conter:

- Código
- Configurações
- Scripts
- Logs
- Screenshots
- Diagramas
- Resultados de testes
- Análises
- Documentação técnica

O objetivo é demonstrar **o processo e o conhecimento aplicado**, não apenas o resultado final.

---

**uso de IA**

A Inteligência Artificial pode ser utilizada como ferramenta de apoio durante os projetos para:

- pesquisa;
- aprendizado;
- revisão de código;
- análise;
- documentação;
- geração de testes;
- automação.

O entendimento dos conceitos, a validação dos resultados e as decisões técnicas permanecem como parte do processo de desenvolvimento.
