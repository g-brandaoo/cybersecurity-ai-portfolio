**visão geral**

Os fundamentos são a base de todo o roadmap.

Antes de trabalhar com ferramentas específicas de segurança, é necessário compreender como sistemas operacionais, redes, aplicações, código e ambientes de desenvolvimento funcionam.

A trilha de fundamentos está dividida em quatro áreas principais:

- Linux
- Redes
- Programação
- Git & GitHub

O objetivo não é apenas conhecer comandos ou conceitos isolados, mas entender **como as diferentes partes de um sistema se conectam**.

**método de estudo**

A progressão recomendada para cada conceito é:

```text
Conceito
   ↓
Teoria
   ↓
Prática
   ↓
Laboratório
   ↓
Projeto
   ↓
Documentação
   ↓
Revisão
```

O objetivo é evitar o aprendizado puramente teórico.

Um conceito só deve ser considerado consolidado quando houver capacidade de **explicá-lo, aplicá-lo e documentá-lo**.
